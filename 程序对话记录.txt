程序对话记录 —— 鼠标画笔（ScreenPen）
===============================================
记录时间：2026-10-26
作者：军哥懂保    微信：xunijiayuan

-----------------------------------------------
一、需求沟通
-----------------------------------------------
用户：做一个鼠标画笔。

助手：目录为空，本机可用 Python 3.7.9 + PyQt5 + tkinter。
      开始前确认两个关键点：
      1）交付形态（桌面版 / 桌面+网页 / 仅网页）
      2）单人本地使用还是多人使用

用户选择：桌面版 + 网页演示版；单人本地使用。

实现决定：
· 桌面版：Python + PyQt5，全屏透明覆盖层，可在任意软件画面上标注。
· 网页版：单文件 HTML，浏览器内画板，手机/平板/电脑自适应。
· 不做登录与后台，配置与存档全部保存在本机。

-----------------------------------------------
二、实现内容
-----------------------------------------------
1）桌面版 鼠标画笔.py
   - 全屏透明画笔层，支持多显示器（虚拟桌面拼成一张画布）
   - 8 个工具：画笔、荧光笔、直线、箭头、矩形、椭圆、文字、橡皮
   - 8 种颜色、笔宽 1-40（滚轮可直接调节）
   - 撤销 / 重做 / 清空 / 合成截图
   - 绘画模式 与 穿透模式 一键切换（穿透时鼠标可以直接操作下层软件，笔迹保留）
   - 黑金 2027 风格控制面板，可拖动、可收起为悬浮球，位置记忆
   - 截图存档：文件存入 截图存档 目录，history.json 保留最近 100 条记录
   - 配置记忆：工具、颜色、笔宽、面板位置、启动模式存入 config.json
   - 说明面板 + 右上角“?”名词解释（全部大白话）
   - 关于面板显示：程序大小、最后修改时间、运行时长、作者、微信
   - 全局热键（Ctrl+Alt+D 切换、H 隐藏、Z 撤销、Y 重做、C 清空、S 截图、Q 退出、1-8 切工具）
   - 预留本地 HTTP 接口 127.0.0.1:9527（/status /history /tools /toggle /mode /clear
     /undo /redo /save /tool /color /width），可用 --no-api 关闭

2）网页演示版 web_demo.html
   - 同一套工具、颜色、笔宽、撤销/重做/清空/导出
   - 浏览器本地存档（localStorage，可恢复、可删除）
   - 手机 / 平板 / 电脑自适应布局（小屏时面板移到底部，可收起）
   - 关于、使用说明、右上角“?”名词解释
   - 预留接口 window.ScreenPenDemo（setTool/setColor/setWidth/undo/redo/clear/save/status）

3）启动鼠标画笔.bat —— 双击即可后台启动（优先 pythonw，无控制台黑窗）。

四、使用方式
-----------------------------------------------
桌面版：双击 启动鼠标画笔.bat（或运行 python 鼠标画笔.py）

        截图自动保存在 截图存档 文件夹。

接口调用示例：
    curl http://127.0.0.1:9527/status
    curl -X POST http://127.0.0.1:9527/toggle
    curl -X POST http://127.0.0.1:9527/save

七、使用演示：框选与区域标注（2026-10-27）
-----------------------------------------------
用户需求：怎么使用，演示——在某张图片或某个区域框选、在某个区域标注。

核心原理：程序是一层覆盖全屏的"透明玻璃"，永远浮在所有窗口之上。
           笔迹画在独立透明层上，不破坏原画面，随时可撤销/清空。

两个场景的标准操作：
场景A 框选某个区域
  1) 打开要处理的图片/网页/软件，让它显示在屏幕上
  2) 用悬浮球选"矩形"（或按 Ctrl+Alt+5）
  3) 按住鼠标左键，从左上角拖到右下角，松开即成一个框
  4) Ctrl+Alt+S 保存合成图（原画面+你的框）
  提示：框只是"画上去"的，不会真的裁剪；若要只保存框内区域，需另加"区域截图"功能。

场景B 在某个区域标注
  · 箭头指示：Ctrl+Alt+4，从起点拖到终点
  · 椭圆圈重点：Ctrl+Alt+6
  · 荧光笔高亮：Ctrl+Alt+2（半透明粗线，底下内容仍可见）
  · 文字说明：Ctrl+Alt+7，点一下位置后输入文字
  · 橡皮擦：Ctrl+Alt+8，只擦自己的笔迹
  · 保存：Ctrl+Alt+S

关键提示：
  · 右键点一下屏幕 = 切换"绘画/穿透"。穿透状态下能正常操作下面的软件（滚网页、点按钮），笔迹保留。
  · 绘画状态下鼠标被画笔接管，无法点击下面的软件。
  · 选错颜色/笔宽可随时在控制台调整，笔宽范围 1-40。

快捷键总表：
  Ctrl+Alt+D  切换 绘画/穿透
  Ctrl+Alt+1  画笔    Ctrl+Alt+2  荧光笔   Ctrl+Alt+3  直线   Ctrl+Alt+4  箭头
  Ctrl+Alt+5  矩形    Ctrl+Alt+6  椭圆     Ctrl+Alt+7  文字   Ctrl+Alt+8  橡皮
  Ctrl+Alt+Z  撤销    Ctrl+Alt+Y  重做     Ctrl+Alt+C  清空
  Ctrl+Alt+S  截图保存 Ctrl+Alt+H 隐藏/显示笔迹层  Ctrl+Alt+Q 退出

已生成效果演示图：截图存档\操作演示_框选与标注.png
（真实屏幕叠加：金色矩形框 + 红色椭圆 + 青色荧光笔 + 红色箭头 + 文字标注）

八、修复"点击无效果" + 区域截图 + F2 开关（2026-10-27）
-----------------------------------------------
用户反馈：我刚刚点击了没有效果；要求补区域截图、加 F2 启动/关闭画笔、并演示。

【根因定位（重要）】
画笔层设置了 WA_TranslucentBackground，Windows 会把它变成"分层窗口"，
鼠标命中按像素 alpha 判定：笔迹层绝大部分像素是完全透明的，导致鼠标
直接"漏"到下层窗口，画笔永远收不到点击。这就是"点击没效果"的真正原因。
诊断方法：WindowFromPoint 查询命中窗口 → 命中的是 IDE 而非画笔层。

【修复】
Board.paintEvent 中先铺一层 alpha=1 的底色（肉眼不可见），
保证全屏每个像素 alpha>0，鼠标命中不再穿透。
验证：修复前 strokes=0，修复后真实拖拽 strokes=1 正常增长。

【新增功能1：区域截图】
· 面板第 2 行新增"区域截图"按钮（4×2 按钮网格，整齐排列）
· 点击后进入框选状态，按住左键拖出区域，松手即把框内画面（含笔迹）裁剪保存
· 保存到 截图存档\ScreenPen_区域_时间戳.png，并写入存档记录
· 本地接口新增 POST /region {x,y,w,h}，方便其他程序调用
· 实测：拖出 880×600 区域，成功生成图片，内容完整

【新增功能2：F2 一键开关画笔】
· F2 注册为单键全局热键（VK=0x71，MOD_NOREPEAT），不再依赖 Ctrl+Alt 组合
· 按一下开启画笔（可直接画），再按一下关闭（可正常点击软件，笔迹保留）
· 实测：paint → through → paint 三次切换均正确
· 提醒：F2 被占用后，在资源管理器等程序里按 F2 改名会失效

【快捷键现状】
  F2          一键开关画笔（重点推荐）
  Ctrl+Alt+D  切换绘画/穿透
  Ctrl+Alt+1~8 选工具  Ctrl+Alt+Z/Y 撤销/重做
  Ctrl+Alt+S  整屏截图  Ctrl+Alt+C 清空  Ctrl+Alt+H 隐藏  Ctrl+Alt+Q 退出

5. 面板按钮区改为 4×2 整齐网格；提示条更新为"F2 开关画笔 · F3 收起/展开界面 · 右键切换绘画/穿透"

清除方法汇总：
  · 面板"清空"按钮 / Ctrl+Alt+C 清空全部
  · Ctrl+Alt+Z 撤销上一笔
  · F2 关画笔后鼠标才能正常点击面板

界面找回：
  · F3 切换面板/悬浮球
  · 悬浮球左键=工具图标盘，右键=菜单（展开控制台 / 退出程序）
